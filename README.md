# 大学校园版美团（meituan-shop-project）

> 以大学为运营方的校园生活服务平台：点餐、自提、集配点配送、拼单、团购、跑腿。
> 核心设计重点：**合规的商家分账**（微信支付服务商模式 + 特约商户 + 服务商分账）。

## 关键前提

1. 平台不碰钱：资金由微信支付直接清分给商户，规避二清。
2. 平台补贴不进入分账，差额走对公月结。
3. 只做 T+1 自动结算，不做资金池、不做提现审批。
4. 单校 2500 单/日下纯外卖模式难盈利，需精简固定成本 + 多元收入。
