> 版本：v1.0 ｜ 字段与状态以 [00](00-术语与口径.md)、[04](04-数据模型与核心流程.md) 为准。

## 1. 基础约定

| 项 | 约定 |
|---|---|
| Base URL | `https://api.{domain}/api` |
| 版本 | URL 版本 `/api/v1/...`；破坏性变更升 v2 |
| 协议 | HTTPS，JSON（`Content-Type: application/json`） |
| 时间 | ISO-8601 带时区，`2026-11-08T12:30:00+08:00` |
| 金额 | 整数分；字段名以 `Amount`/`Fee`/`Price` 结尾 |
| 字段命名 | camelCase |
| 空值 | 不返回 `null` 字段或返回 `null` 由 OpenAPI 约定；数组返回 `[]` |
| 幂等 | 写接口要求 `X-Request-Id`（UUID）；下单额外要求 `submitToken` |
| 追踪 | 响应返回 `traceId`；请求可带 `X-Trace-Id` |
| 限流 | 按 IP + 用户 + 接口；超限返回 429 |

### 1.1 请求头

| Header | 说明 |
|---|---|
| `Authorization: Bearer {accessToken}` | 登录后必带 |
| `X-Client` | `student` / `merchant` / `rider` / `admin` |
| `X-Campus-Id` | 当前校区（服务端仍校验权限） |
| `X-Request-Id` | 幂等键，UUID |
| `X-Device-Id` | 设备标识（风控） |

### 1.2 统一响应

```json
{
  "code": "0",
  "message": "ok",
  "data": {},
  "traceId": "9f2c...",
  "timestamp": "2026-11-08T12:30:00+08:00"
}
```

失败：

```json
{
  "code": "50003",
  "message": "库存不足",
  "data": null,
  "traceId": "9f2c...",
  "timestamp": "2026-11-08T12:30:00+08:00"
}
```

### 1.3 分页

```json
{
  "code": "0",
  "data": {
    "list": [],
    "pageNum": 1,
    "pageSize": 20,
    "total": 135,
    "hasNext": true
  }
}
```

- `pageNum` 从 1 开始，`pageSize` 最大 100；
- 信息流/评价用游标：`cursor` + `hasNext`；
- 禁止深分页（`pageNum * pageSize > 10000` 返回错误）。

### 1.4 错误码

格式：**模块 1 位 + 业务 4 位**。HTTP 状态与业务码分离（业务失败通常 HTTP 200）。

| 段 | 模块 |
|---|---|
| `1xxxx` | 用户/认证 |
| `2xxxx` | 校园/地址 |
| `3xxxx` | 商家 |
| `4xxxx` | 商品/库存 |
| `5xxxx` | 订单/售后 |
| `6xxxx` | 资金/支付/分账 |
| `7xxxx` | 配送/骑手 |
| `8xxxx` | 营销/会员 |
| `9xxxx` | 评价/投诉 |
| `0xxxx` | 系统/通用 |

常用：

| code | 含义 |
|---|---|
| `10001` | 未登录/Token 失效 |
| `10003` | 无权限 |
| `10004` | 学生认证未通过 |
| `30001` | 商家未营业 |
| `30002` | 商家资质过期 |
| `40001` | 商品不存在 |
| `40002` | 库存不足 |
| `40003` | 未达起送价 |
| `50001` | 订单不存在 |
| `50002` | 订单状态不允许该操作 |
| `50003` | 重复提交 |
| `50004` | 超出预约产能 |
| `60001` | 支付单不存在 |
| `60002` | 支付失败 |
| `60003` | 退款金额超过可退 |
| `60004` | 分账金额校验失败 |
| `60005` | 分账回退失败 |
| `70001` | 骑手未认证 |
| `70002` | 配送单已被接 |
| `80001` | 优惠券不可用 |
| `80002` | 活动已结束 |
| `90001` | 评价已提交 |
| `00001` | 系统繁忙 |
| `00002` | 参数错误 |
| `00003` | 限流 |

## 10. 实时通信

| 场景 | 方案 |
|---|---|
| 订单状态 | WebSocket `/ws/orders`（学生/商家/骑手），失败降级 15s 轮询 |
| 骑手位置 | 学生端 5s 轮询 `/v1/orders/{no}/rider-location`；或 WebSocket 订阅 |
| 新订单提醒 | 商家端 WebSocket + 订阅消息 + 语音 |
| 系统公告 | 站内信 + 订阅消息 |

**WebSocket 鉴权：** 连接时带 Access Token；服务端校验角色与资源归属；心跳 30s；断线重连指数退避。

## 12. OpenAPI 与契约

- 使用 Springdoc 生成 OpenAPI 3；
- 前端用 `openapi-typescript` 生成类型，禁止手写重复类型；
- 接口变更必须更新 OpenAPI 并跑契约测试；
- 破坏性变更：新增字段可兼容；删除/改类型必须升版本；
- 所有接口提供示例请求/响应与错误码。
