## 2. 核心合规红线

### 2.1 二清（最高优先级）

- 平台/学校**不得**统一收款再转付商户；
- 资金必须由持牌机构直接清分；
- 不得形成资金池（保证金、余额、充值、代付都需单独评估）；
- 不得由平台自行决定结算时间/金额；
- 详见 [05](05-支付与分账方案.md) 第 1 节。

### 2.2 教育公益与收费

- 教发〔2011〕7 号：食堂零租赁、免管理费、学校不得从食堂盈利；
- 平台服务费只能由独立法人以真实技术服务收取，价格公允、非排他；
- 不向学生收平台服务费；
- 保留商户选择权，避免《公平竞争审查条例》风险。

### 2.3 网络餐饮平台义务

- 平台备案、许可证公示、食安管理人员；
- 商家资质审核、定期核验、违规下线；
- 配送箱消毒、食安封签、配送过程管理；
- 食安事故报告与处置；
- 交易信息保存不少于 3 年（与个人信息最小化冲突时，去标识化分层保存）。

### 2.4 电子商务法

- 平台主体与规则公示；
- 交易信息保存不少于 3 年；
- 知识产权、消费者权益保护；
- 配合监管、提供数据。

### 2.5 个人信息保护（PIPL）

| 数据 | 要求 |
|---|---|
| 手机号、学号 | 最小必要、加密存储、展示脱敏 |
| 位置（学生/骑手） | 单独同意、可撤回、仅配送期间采集 |
| 支付信息 | 不落地银行卡/CVV；支付由微信完成 |
| 人脸（如使用） | 单独同意、替代验证、备案 |
| 消费记录 | 不得默认用于精准营销；需单独同意 |
| 数据出境 | 禁止（首期全部境内） |
| 保存期限 | 订单/资金 10 年（法定）；轨迹 90 天；日志 180 天 |
| 用户权利 | 查询、更正、删除、导出、注销 |

### 2.6 用工与保险

- 学生骑手：勤工助学/劳务协议，明确非劳动关系；购买意外险；不得安排超时/危险配送；
- 校外骑手：劳务公司/灵活用工平台，代扣个税；
- 工伤/交通事故责任划分写进协议；
- 未成年人不得注册骑手。

### 2.7 税务与发票

- 谁收款谁开票：商户开给学生；运营公司开技术服务费给商户；配送公司开配送费；
- 平台补贴按全额确认收入 + 营销费用，或按销售折让（需税务师意见）；
- 退款红冲时点与流程；
- 三流一致（合同、资金、发票）。

## 5. 应急预案（Playbook）

### 5.1 支付不可用

1. 5 分钟内确认范围（微信侧/我方）；
2. 关闭新下单支付入口，展示公告；
3. 已下单未支付订单延长 30 分钟；
4. 恢复后主动查单补偿；
5. 2 小时内出故障报告。

### 5.2 分账失败

1. 告警后 30 分钟内定位（余额/限额/账户/网络）；
2. 自动重试 3 次；
3. 仍失败转人工，不影响用户与商户结算凭证；
4. 次日对账核对，生成差异工单。

### 5.3 运力断档

1. 午峰前 1 小时预测缺口；
2. 启用保底奖励、跨区调度、配送公司兜底；
3. 关闭部分商家接单/延长预计送达；
4. 公告用户，超时自动赔付。

### 5.4 食安事故

1. 2 小时内响应，涉事商品/商家下架；
2. 保留留样、订单、评价证据；
3. 陪同就医/赔付；
4. 报告学校与市场监管；
5. 24 小时内出初步报告，72 小时整改。

### 5.5 舆情

1. 1 小时内监测到并内部通报；
2. 统一口径，指定发言人；
3. 不与用户在公开平台争论；
4. 校方联动，24 小时内回应。

### 5.6 校方叫停

1. 立即停止新订单；
2. 商户结算、用户退款；
3. 数据封存与移交；
4. 按合同启动退出条款。

### 5.7 极端天气

1. 自动延时免责、关闭部分区域；
2. 骑手补贴、安全提示；
3. 公告与退款绿色通道。

### 5.8 数据泄露

1. 30 分钟内断源、取证；
2. 评估影响范围；
3. 72 小时内向监管与用户报告（如适用）；
4. 修复、复盘、审计。
