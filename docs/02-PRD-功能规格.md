# 02 · PRD 功能规格

> 版本：v1.0 ｜ 状态码、金额、优先级以 [00-术语与口径](00-术语与口径.md) 为准。

## 1. 范围与端

| 端 | 载体 | 用户 | 首期 |
|---|---|---|---|
| 学生端 | 微信小程序（uni-app），H5 兜底 | 学生 | P0 |
| 商家端 | 微信小程序 + PC Web | 食堂档口/校内店/校外店 | P0 小程序，P1 PC |
| 骑手端 | **App（uni-app 打包）为主**，小程序仅作查询 | 学生兼职骑手 | P0 |
| 管理后台 | PC Web（Vue3 + Element Plus） | 平台运营/财务/客服/校方 | P0 |

> 骑手端必须用 App：小程序无法后台持续定位与厂商推送，是硬约束。

## 2. 学生端

### 2.1 首页与发现

| 功能 | 规则 |
|---|---|
| 校区/楼栋切换 | 首次进入按定位推荐校区；默认只展示本校区的商家与活动 |
| 分类导航 | 食堂、外卖、奶茶、水果、超市、跑腿；分类由后台配置 |
| 商家列表 | 按距离/评分/销量/出餐速度排序；默认「综合」= 销量 40% + 评分 30% + 距离 30% |
| 营业状态 | 打烊商家置底并标注；假期模式自动隐藏 |
| 搜索 | 关键词、历史、热搜；店铺与商品混合结果；无结果推荐同类 |
| 活动位 | Banner、限时秒杀、拼单广场、新人专区；后台可配置跳转 |

### 2.2 店铺与商品

- 店铺详情：公告、评分、月售、预计送达、起送价、打包费、配送方式、资质公示。
- 菜单：分类、SPU/SKU、规格/加料、库存、售罄置灰、图片。
- 商品详情：图片、描述、规格、价格、月售、评价摘要。
- 资质公示：营业执照、食品经营许可证（按法规要求展示）。
- 收藏/分享。

### 2.3 购物车与下单

| 步骤 | 规则 |
|---|---|
| 加购 | 多规格必须选完；库存不足提示；跨店加购需清空或分开下单（首期不做跨店合并支付） |
| 起送价 | 未达起送价不可下单；起送价按商家配置 |
| 配送方式 | 送楼下 / 送上门 / 集配点自提 / 到店自提；不同方式不同配送费 |
| 预约时间 | 5 分钟粒度；受档口产能时段限制；最早 15 分钟后 |
| 地址 | 楼栋级下拉，不手打；默认地址；门牌/备注 |
| 优惠 | 自动优选最优券；商家券与平台券可叠加规则由后台配置；显示优惠明细 |
| 备注 | 餐具份数、口味、放门口等；敏感词过滤 |
| 提交 | `submitToken` 防重复；生成订单号；锁定库存；15 分钟未支付自动关闭 |

### 2.4 支付

- 微信支付（主）；免密代付（单笔 ≤50 元，需签约）；校园卡（P2）。
- 支付结果页：成功/失败/处理中；失败可重试；超时订单关闭。
- **不提供余额充值/钱包**（首期）。

### 2.5 订单

- 列表：全部/进行中/待评价/退款；分页。
- 详情：状态时间轴、骑手位置（配送中）、预计送达、商家/骑手联系方式（虚拟号）。
- 操作：取消（未接单可直接取消；已接单需商家同意）、催单、再来一单、申请退款、联系客服、分享。
- 状态刷新：WebSocket 推送 + 轮询兜底（15 秒）。

### 2.6 售后

| 场景 | 规则 |
|---|---|
| 未接单取消 | 秒退，原路退回 |
| 已接单未出餐 | 商家审核；超 10 分钟未处理自动退款 |
| 已出餐/配送中 | 平台客服介入；按责任判定 |
| 已送达 | 售后期 2 小时内可申请；食安投诉走专项工单 |
| 部分退款 | 按商品行退；优惠按比例分摊 |
| 食安投诉 | 必须上传照片/描述；2 小时响应；涉事商品下架 |

### 2.7 评价

- 星级 1–5 + 标签 + 图片（最多 9 张）+ 匿名。
- 评价资格：订单完成后 7 天内；每单一次。
- 商家可回复一次；平台可审核/隐藏违规。
- 评价返券（后台配置）。

### 2.8 会员与资产（P1）

- 校园会员：9.9 元/月、25 元/季、88 元/学期；免配送费 20 次/月 + 专属券。
- 券包、积分（下单/评价/邀请获得，抵扣或换券）。
- 学生认证：学号 + 教务/校园网/学生证 OCR；认证后享学生价与免密。
- 邀请有礼：邀请新用户首单后双方得券；防刷（同设备/同支付账号限制）。

### 2.9 校园特色（P1/P2）

- 拼单房：创建/分享/加入/结算；同楼栋同商家 30 分钟窗口；合并出餐配送。
- 团购：团长开团、阶梯价、指定集配点自提、团长分佣（券/余额）。
- 跑腿：代取快递/代买/代打印/搬水；计价、接单、轨迹、完成拍照。
- 假期专区：留校生可用商家与次日达集配。
- 失物招领、二手市场（P2）。

## 3. 商家端

### 3.1 入驻与资质

- 提交：主体信息、营业执照/事业单位法人证书、食品经营许可证、法人身份证、结算账户、门店照片。
- 电子合同签署、分账授权书签署（**必须与进件同时完成**）。
- 审核：平台初审 → 微信特约商户进件 → 审核通过 → 开店。
- 资质到期预警（提前 30 天）；过期自动下线。

### 3.2 店铺管理

- 营业时间、营业日历、假期模式一键歇业、忙碌模式（延长出餐时间/暂停接单）。
- 店铺公告、门店信息、配送范围、自提点绑定、打印机绑定。
- 配送方式与配送费配置（送楼下/送上门/集配/自提）。

### 3.3 商品管理

- 分类、SPU/SKU、规格/加料、价格、库存、售罄开关、套餐、批量导入导出。
- 商品审核（图片合规、违禁词）；上下架。
- 库存：每日库存/无限库存；低库存提醒。

### 3.4 订单管理

- 新单语音 + 震动 + 弹窗；自动接单开关。
- 接单/拒单（拒单需原因，自动退款）；出餐完成；异常单处理。
- **接单超时规则**：30 秒提醒 → 3 分钟二次提醒 → 5 分钟未接单自动取消并退款（可按商家配置 3–10 分钟）。
- 退款审核：10 分钟内处理，超时自动同意。
- 订单搜索、导出、打印小票。

### 3.5 履约

- 出餐时长设置、备餐预估、骑手到店提醒、自提核销扫码、缺货替换/部分退款。

### 3.6 财务

- 账单流水、结算记录（T+1）、佣金明细、对账单导出、发票申请。
- **不提供提现审批**：资金由微信直接结算到商户银行卡，平台不做代付。

### 3.7 数据与消息

- 营业额、单量、客单价、热销商品、退款率、评分、时段热力图。
- 平台公告、违规/处罚通知、申诉入口、客服。

## 4. 骑手端

### 4.1 注册与认证

- 实名认证、学生认证、健康证、校园通行证、线上培训与考试。
- 意外险投保（按单或按月）；保证金（首期不做）。

### 4.2 接单与排班

- 抢单大厅 + 系统派单；接单上限（同时 3–5 单）。
- 可上线时段设置；班次（午/晚/夜宵）；班次保底单量。
- 派单规则：距离优先 + 顺路合并 + 负载均衡；60 秒未响应进入抢单池并扩大范围。

### 4.3 配送

- 楼栋级导航、门禁提示、取餐码核验、送达拍照/扫码。
- 集配点批量投柜/上架。
- 异常上报：联系不上、门禁、天气、餐损、交通事故。
- 离线模式：弱网缓存订单与状态，恢复后同步。

### 4.4 收入与安全

- 日/周收入、订单明细、奖励/罚款明细、T+1 结算。
- 意外险、SOS、超速提醒、服务评分、申诉。

## 6. 关键业务规则

### 6.1 订单生命周期

```
10 待支付 --支付--> 20 待接单 --商家接单--> 30 制作中 --出餐--> 35 待取餐
   |                    |                      |                  |
   |15min超时           |拒单/5min超时          |                  |骑手取餐
   v                    v                      v                  v
  91 已关闭            90 已取消              90 已取消          40 配送中
                                                                  |
                                                            骑手送达
                                                                  v
                                                            45 已送达
                                                           /          \
                                                     售后期结束      申请售后
                                                          v              v
                                                      50 已完成      60 售后中
```

### 6.2 取消规则

| 阶段 | 用户取消 | 商家取消 | 平台取消 |
|---|---|---|---|
| 10 待支付 | 直接取消 | — | 超时关闭 |
| 20 待接单 | 直接取消，秒退 | 需原因，秒退 | 可强制取消 |
| 30 制作中 | 需商家同意；商家拒绝则继续 | 需原因，退款 + 处罚 | 客服介入 |
| 35 待取餐 | 需商家同意 | 退款 + 处罚 | 客服介入 |
| 40 配送中 | 不可取消，走售后 | 不可取消 | 异常时介入 |

### 6.3 接单与出餐

- 接单超时：30 秒提醒、3 分钟二次提醒、5 分钟自动取消退款（商家可配置 3–10 分钟）。
- 出餐超时：预计出餐时间 + 10 分钟告警；+20 分钟可申请平台介入。
- 商家「忙碌模式」：延长出餐时间或暂停接单，每日最长 2 小时。

### 6.4 配送与派单

- 派单：距离 40% + 顺路 30% + 负载 20% + 评分 10%。
- 60 秒未接单 → 抢单池 → 扩大 500 米 → 再 60 秒 → 人工调度。
- 超时：预计送达 + 15 分钟告警；+30 分钟触发赔付。
- 异常：骑手上报后，客服 5 分钟内介入，可改派/退款。

### 6.5 预约与产能

- 档口配置每 5 分钟可接单量（如 12 单/5 分钟）。
- 预约单占用产能；售完即止；商家 T-15 分钟收到备餐提醒。
- 超时未取：30 分钟内退 50%，2 小时后不退。

### 6.6 拼单

- 条件：同楼栋 + 同商家 + 30 分钟窗口 + 最多 10 人。
- 发起人支付自己的部分；未支付成员 10 分钟后踢出。
- 全部支付后合并为一单出餐、一单配送；任一成员退款按比例分摊。
- 防刷：同一账号 24 小时最多发起 5 次拼单。

### 6.7 优惠分摊

- 商家券/满减：按商品行金额比例分摊，尾差归最大行。
- 平台券：按商品行比例分摊，平台承担；不减少商家应收。
- 退款时按分摊比例回退；已分账走分账回退。

### 6.8 评价与信用

- 完成后 7 天内可评价；恶意差评/刷单经核实可隐藏并扣信用分。
- 信用分 <500 限制免密/货到付款；<400 封禁。

### 6.9 假期模式

- 后台录入校历；假期自动切换；商家可一键歇业；留校生专区；结算照常。

## 7. 异常流程

| 异常 | 处理 |
|---|---|
| 支付成功但订单未更新 | 主动查单 + 回调补偿；5 分钟内修复 |
| 商家 5 分钟未接单 | 自动取消退款；通知用户 |
| 骑手 60 秒未接单 | 进抢单池、扩围、人工调度 |
| 骑手联系不上用户 | 上报客服；放置指定点拍照；30 分钟后可完成 |
| 餐损/撒漏 | 骑手上报 + 拍照；全额或部分退款；责任判定 |
| 食安投诉 | 专项工单；2 小时响应；商品下架；留样送检 |
| 系统故障 | 降级开关：关闭下单/支付/配送；公告；恢复后对账 |
| 重复支付 | 幂等 + 自动退款多付部分 |
| 分账失败 | 重试 3 次；仍失败转人工；不影响用户 |
| 对账差异 | 差异工单；T+3 闭环 |

## 8. 验收用例（节选）

| # | 场景 | 预期 |
|---|---|---|
| AC-01 | 未达起送价下单 | 按钮置灰，提示差额 |
| AC-02 | 重复点击提交 | 只生成一单（submitToken + 唯一索引） |
| AC-03 | 支付成功回调重复 3 次 | 订单只更新一次，返回成功 |
| AC-04 | 商家 5 分钟未接单 | 订单 90 已取消，原路退款，用户收到通知 |
| AC-05 | 骑手送达后 2 小时内申请退款 | 进入 60 售后中，客服可仲裁 |
| AC-06 | 部分退款 | 按商品行比例退，优惠按比例回退，分账已执行则走分账回退 |
| AC-07 | 预约单超过档口产能 | 不可选该时段，提示已约满 |
| AC-08 | 拼单 3 人各自支付 | 合并为一单出餐配送，分摊金额正确 |
| AC-09 | 假期模式 | 商家自动下架，留校生专区可见 |
| AC-10 | 分账金额 > 用户实付 | 拦截并转人工，不调用微信分账 |
| AC-11 | 分账回退失败 | 用户仍全额退款，生成欠款台账 |
| AC-12 | 商家资质过期 | 自动下线，不可接单 |
| AC-13 | 骑手离线恢复 | 订单状态同步，无重复/丢失 |
| AC-14 | 后台退款 600 元 | 需双人复核 + 审计日志 |
| AC-15 | 跨校区访问 | 只能看到本校区数据（数据权限） |
