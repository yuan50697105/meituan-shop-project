# 01 · 产品定位与商业模式

> 版本：v1.0 ｜ 口径以 [00-术语与口径](00-术语与口径.md) 为准。

---

## 1. 定位

**校园内 30 分钟生活圈平台**：把食堂档口、校内商铺、校外商家和学生兼职运力组织起来，提供「点餐 + 自提 + 配送到楼 + 拼单 + 团购 + 跑腿」的一站式服务。

**不是缩小版美团。** 社会外卖的模型是「高客单 + 高抽佣 + 专职运力」；校园的客单价只有 15–20 元、抽佣空间小、运力是碎片化的学生。校园平台的第一性原则是：

> **用密度把单均配送成本压到 1 元级，用预约和集配把饭点波峰削平，用组织和拼单把获客成本降到接近零。**

## 2. 三个结构性优势

| 优势 | 说明 | 对应设计 |
|---|---|---|
| **密度** | 1.5km 内 3 万人，订单密度是社会城区 5–10 倍 | 一次带 8–15 单的集配模型 |
| **组织** | 班级、宿舍、社团天然存在 | 拼单、团购、校园大使裂变 |
| **时间可预测** | 课表统一，需求可预测 | 预约制、课表排班、产能时段 |

## 3. 用户与角色

| 角色 | 核心诉求 | 成功标准 |
|---|---|---|
| 学生 | 便宜、准时、送到楼下、别丢、能拼单 | 30 秒复购下单；准时率 ≥90%；实付 ≤15 元 |
| 商家（食堂档口/校内店/校外店） | 多接单、少出错、结算快、抽佣低 | 出餐 ≤12 分钟；缺货率 <3%；线上单占比 ≥30% |
| 骑手（学生兼职为主） | 课间可跑、单量稳定、结算快、有保险 | 时薪 ≥15 元；单均 ≤18 分钟；30 日留存 ≥60% |
| 学校 | 安全、可控、食安可追溯、舆情可控 | 重大食安事故 0；骑手备案 100% |
| 平台运营 | 资质、准入、异常、分账、食安五件事可控 | 分账准确率 100%；对账差异 T+3 闭环 |

## 4. 校园差异化机制（12 条，均可配置）

| # | 机制 | 关键规则 |
|---|---|---|
| D1 | 楼栋级地址 + 分层配送 | 地址：校区→园区→楼栋→单元→楼层→房间；默认送楼栋大厅；4 层以上无电梯 +0.5 元楼层费；女生宿舍按学校规定仅楼下交付 |
| D2 | 集配点 / 自提柜 | 每 2–3 栋宿舍 1 个点，全校 8–12 个；骑手批量投递，学生凭码自取；自提配送费 1.0–1.5 元，引导 55% 订单走集配+自提 |
| D3 | 拼单 | 同楼栋 + 同商家 + 30 分钟窗口；满 2 单免配送费，满 5 单每人减 1 元，满 10 单 9 折；系统合并为一单出餐、一单配送 |
| D4 | 预约自提 + 食堂错峰 | 档口配置每 5 分钟可接单量；下课前预约、到点扫码取餐；自提免配送费 + 9.5 折；超时 30 分钟内可退 50% |
| D5 | 支付方式 | 微信支付（主）、免密代扣（单笔 ≤50 元）、校园卡（P2，视接口开放）；**首期不做余额钱包/充值** |
| D6 | 课表驱动排班 | 学生骑手手动填可上线时段（课表导入为 P2）；按 11:50–12:50、17:30–18:30、21:00–22:30 三班次排班；闲时 14:00–16:00 每单 +0.5 元 |
| D7 | 班级/社团/寝室团购 | 团长开团，阶梯价 10 份 9 折、20 份 85 折、50 份 8 折；团长收益以免配送费 + 2% 余额/券发放，**不发现金返佣** |
| D8 | 跑腿 | 代取快递、代买、代打印、搬水；起步 3 元（1km/5kg 内），超距 +1 元/km，超重 +2 元/5kg；仅认证学生可接单 |
| D9 | 寒暑假模式 | 校历驱动学期/假期切换；商家一键歇业、自动下架、结算照常；留校生专区；开学季预售卡券 |
| D10 | 学生认证与信用 | 学号+教务/校园网/学生证 OCR 三选一；认证享学生价、免密、跑腿资格；信用分 300–850，恶意退款/刷单扣分 |
| D11 | 校园准入与骑手白名单 | 签《校园配送服务协议》；骑手实名备案、通行证、意外险；限速 15km/h、禁入教学区、违规三次取消资格 |
| D12 | 多校区隔离 | 每校区独立商家池、运力池、配送费、活动；默认只显示本校区；跨校区专线列为 P2，首期不做 |

> 附加：考试周静音配送、雨天自动延时免责、毕业季行李搬运、新生季礼包。

## 5. 功能范围与优先级

### P0（M1–M2，闭环必需）

- 学生端：登录/学生认证、校区与楼栋地址、店铺列表与详情、商品与规格、购物车、下单、微信支付、订单状态、取消/退款、评价入口。
- 商家端：入驻与资质、店铺/商品管理、接单/拒单、出餐、订单查询、结算账单。
- 骑手端：认证、接单/派单、取餐、送达、收入明细。
- 管理后台：商家审核、订单查询、退款仲裁、分账配置、对账、基础报表。
- 资金：微信支付、服务商分账、T+1 结算、退款、日对账。

### P1（M3–M4，完整体验与增长）

- 预约自提与产能时段、集配点/自提柜、拼单、优惠券/满减、会员卡、评价与投诉、食安工单、骑手排班、消息通知、BI 看板。
- 商家 PC 后台（P0 先用小程序，P1 补 PC）。

### P2（M5+，差异化与增效）

- 班级/社团团购、跑腿、校园卡对接、课表导入、寒暑假专区、多校区、广告位、二手市场、失物招领、跨校区专线。

### 明确不做（首期）

- 不做余额钱包/充值/储值（预付卡合规风险）；
- 不做跨校/社会化配送、全国扩张；
- 不做直播、AI 推荐、复杂算法调度；
- 不做自建支付通道、不做资金池；
- 不做校外骑手进校（除非学校批准）；
- 不做多商户跨店合并支付（微信服务商分账不支持，需电商收付通）。

## 6. 商业模式与单位经济模型

### 6.1 收入来源

| 来源 | 说明 | 首期 |
|---|---|---|
| 平台佣金 | 食堂 3%（首年 1.5%）、校内商铺 5%、校外商户 6% | ✅ |
| 配送费 | 即时 2.5 元、集配点 1.5 元、到店自提 0 | ✅ |
| 会员 | 9.9 元/月，免配送费 20 次 + 专属券 | P1 |
| 广告 | 首页 Banner、搜索竞价、商家推广位 | P2 |
| 团购/跑腿服务费 | 团购 3%–5%，跑腿抽 15% | P2 |
| 学校购买服务 | 学校支付平台建设/运维/食安监管服务费 | 需谈 |

### 6.2 单均 UE（客单价 18 元 = 商品 16 + 配送 2）

| 履约方式 | 佣金 | 配送费收入 | 配送成本 | 通道费 | 运营摊销 | 单均贡献 |
|---|---|---|---|---|---|---|
| 即时配 | 0.72 | 2.50 | 2.20 | 0.11 | 0.40 | **+0.51** |
| 集配点 | 0.72 | 1.50 | 0.90 | 0.11 | 0.40 | **+0.81** |
| 到店自提 | 0.72 | 0 | 0 | 0.11 | 0.40 | **+0.21** |
| 混合（40/40/20） | — | — | — | — | — | **+0.57** |

> 佣金按 4.5% 混合费率、商品金额 16 元计算。补贴未计入；若补贴 3% GMV（0.54 元/单），单均贡献降至约 0.03 元。

### 6.3 月度盈亏（稳态 2500 单/日）

| 项目 | 金额（万元/月） |
|---|---|
| 佣金收入 | 5.4 |
| 配送费收入 | 12.0 |
| 收入合计 | 17.4 |
| 配送成本 | 9.3 |
| 支付通道费 | 0.8 |
| 运营/客服/技术变动成本 | 3.0 |
| 贡献毛利 | **4.3** |
| 固定成本（精简团队 6–8 人 + 基础设施） | 5.0 |
| 固定成本（标准团队 10–12 人） | 12.0 |
| 净利（精简） | **-0.7** |
| 净利（标准） | **-7.7** |

### 6.4 盈亏平衡

| 固定成本 | 盈亏平衡日单 |
|---|---|
| 5 万元/月 | **约 2,900 单/日** |
| 8 万元/月 | 约 4,700 单/日 |
| 12 万元/月 | 约 7,000 单/日 |

**结论：**

1. 单校 2500 单/日、标准团队，**必然亏损**；必须把固定成本压到 5 万/月以内（学生兼职 + 学校提供场地/资源），并把日单做到 3000 以上。
2. 纯外卖抽佣不是可持续模型。会员、广告、团购、跑腿、学校购买服务必须贡献 30% 以上收入。
3. 多校复制（SaaS 化）是摊薄研发与运维成本的唯一路径，但首期不做多租户，只预留 `campus_id`。
4. 补贴必须严格预算化：**补贴率 ≤3% GMV**，且优先用券/权益而非现金。

## 7. 指标树

**北极星：周有效完成订单数 WCO。**

```
WCO = 认证用户数 × 周活跃率 × 人均周下单频次 × (1 - 取消率)

需求侧：曝光→点击→加购→下单→支付 转化率；新客成本；7/30 日复购
供给侧：在线商家数、SKU 数、出餐时长、缺货率、商家月流失
履约侧：接单率、准时率、单均配送时长、超时率、集配渗透率、骑手时薪/留存
商业侧：GMV、take rate、单均贡献、补贴率、会员付费率、广告收入
护栏：重大食安事故 0、支付成功率 ≥99.5%、分账准确率 100%、对账差异 T+3 闭环、投诉率
```

**阶段目标**见 [README](README.md) 第 4 节。

## 8. 冷启动策略

1. **单点打透**：先做 1 个宿舍区（3000–5000 人）+ 1 个食堂，不做全校。
2. **先签总部，再签档口**：食堂档口由后勤/餐饮承包公司统一签约，避免逐家谈判。
3. **首月策略**：免佣 + 免费菜单拍摄 + 免费打印机 + 驻店陪跑 7 天；校外商家首月免佣。
4. **运力**：20–30 名认证学生骑手，课间班次，保底时薪 + 每单奖励。
5. **增长**：宿舍长/班长成为校园大使，拼单和团购是主要裂变方式；新生季礼包。
6. **目标**：6 个月日单 1500–2500、商家 80–120、7 日复购 35%–40%。

## 9. 风险与假设

| 风险/假设 | 影响 | 应对 |
|---|---|---|
| 集配点场地谈不下来 | 成本模型崩塌 | 立项前与后勤签场地意向；备选自提柜/超市合作 |
| 学生骑手供给不足 | 峰值超时 | 保底时薪、课间排班、校外配送公司兜底 |
| 补贴停即掉单 | GMV 断崖 | 会员/团购/拼单构建非补贴留存；补贴预算化 |
| 食堂档口无执照 | 无法进件分账 | 自营化或限期办照；见 [05](05-支付与分账方案.md) |
| 校方叫停 | 项目终止 | 签校园配送协议、骑手白名单、食安共管；准备退出条款 |
| 食安事故 | 舆情/法律责任 | 资质审核、明厨亮灶、留样、食安险、2 小时响应 |
| 单校不盈利 | 现金流断裂 | 精简固定成本、学校购买服务、多校复制 |
